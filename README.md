# SEMIQOLON · SEMI 성경 BETA

테스트: https://noah-tv.github.io/semi-bible-beta/

2026-10-02 · 한국어 기기 실시간 인식 적용 (`2026-10-02-mobile-stream`).

1. 아이폰은 Safari, 갤럭시·안드로이드는 Chrome에서 링크를 엽니다. 카카오톡 안에서는 메뉴의 다른 브라우저로 열기를 이용하세요.
2. 설정 또는 녹음 화면에서 **문장 인식 준비**를 누릅니다. 처음 약 153 MB이므로 Wi-Fi를 권장합니다. 준비됨 표시 후 녹음하면 읽는 글자가 반응합니다.
3. 성경에서 원하는 절을 선택하고 녹음합니다. **다음**으로 다음 절까지 이어 읽고 **녹음 마치기**를 누릅니다.
4. 기록에서 음성·인식한 글을 확인합니다. 읽기표와 **내 목소리 성경**에 녹음한 절이 표시되고, 각 절의 시작 위치부터 재생할 수 있습니다.

음성과 인식은 기기 안에서 처리합니다. 모델 다운로드 외에는 음성 인식 서버/접속 코드가 필요하지 않으며 분당 인식 API 요금이 없습니다. 인터넷 데이터 요금은 별도입니다. 마이크 입력은 기존 보정 끄기 요청을 유지합니다. 인식 실패·무음·느린 처리 중에도 원래 녹음의 저장 경로는 독립적으로 작동합니다.

기록은 **현재 브라우저**에 저장되며 다른 브라우저·기기와 동기화되지 않습니다. 설정 → 전체 백업을 이용하세요. Google/Apple 로그인은 아직 연결하지 않았습니다. F1·F2 서버 정밀 분석도 이 정적 테스트에는 연결되어 있지 않습니다. 기존 임시 터널 주소는 제거했습니다.

## 인식 범위

한국어 Zipformer를 sherpa-onnx WebAssembly 한 스레드에서 실행합니다. 공식 모델·런타임의 출처와 라이선스는 [안내](licenses/mobile-streaming-NOTICE.md)를 참고하세요. 최초 모델 파일은 SHA-256으로 확인하고 브라우저 캐시에 저장합니다. 캐시가 지워지면 다시 준비해야 합니다.

인식문은 오인식할 수 있고, 옛 성경 표현에는 특히 오류가 남습니다. 화면의 일치 표시를 발음 정확도·성경 완독 인증으로 해석하면 안 됩니다. 읽기표는 실제 녹음 + 사용자의 다음/종료 동작 기준이며 설정에서 수정할 수 있습니다. 20분 연속 녹음 지원; 인식이 30초 이상 밀리면 인식만 중단하고 음성을 보존합니다.

개발 PC의 브라우저에서 실제 음성 샘플, 무음, 짧은 마지막 청크, 두 절 연속 녹음·저장·구절별 재생, 390px 레이아웃을 확인했습니다. 실제 iPhone/Galaxy 하드웨어에서의 인식 속도·메모리 사용은 추가 확인이 필요합니다.
